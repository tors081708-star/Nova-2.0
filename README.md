# Nova-2.0

NOVA 2.0 is an autonomous agent system featuring Memory Layer, Voice I/O, Intelligent CLI, Web Dashboard, and a complete To-Do application with Local Storage functionality.

## Quick Start
- Run Web Server: `python3 -m uvicorn nova.ui.web.server:app --port 8000`
- Run Interactive CLI: `python3 nova/ui/cli/nova_shell.py`
